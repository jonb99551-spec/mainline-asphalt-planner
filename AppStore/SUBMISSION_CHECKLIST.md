# App Store Submission Checklist

## Developer account

- [ ] Enroll in the Apple Developer Program.
- [ ] Complete Agreements, Tax, and Banking in App Store Connect.
- [ ] Consider enrolling in the App Store Small Business Program.

## Xcode

- [ ] Select your development team under Signing & Capabilities.
- [x] Confirm that `com.mainlineasphalt.planner` is registered to your team.
- [ ] Test ascending and descending jobs on a physical iPhone.
- [ ] Test large text, dark mode, VoiceOver, sharing, saving, editing, and deletion.
- [ ] Set the release version/build number if different from 1.0 (1).
- [ ] Product → Archive, then Validate App.
- [ ] Upload the validated build to App Store Connect.

## Store record

- [ ] Reserve “Mainline: Asphalt Planner” in App Store Connect.
- [ ] Enter the listing copy from `STORE_LISTING.md`.
- [ ] Set the paid-app price to USD $9.99.
- [ ] Upload final iPhone screenshots.
- [ ] Host and enter the privacy-policy URL.
- [ ] Enter a working support URL.
- [ ] Complete the age-rating, app-privacy, accessibility, and export-compliance questions.
- [ ] Select the uploaded build and submit it for review.

## Release recommendation

- [ ] Test with 3–5 paving professionals through TestFlight first.
- [ ] Use manual release after approval so launch timing remains under your control.
